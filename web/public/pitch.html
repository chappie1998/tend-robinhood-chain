The trader's problem

A trader can be right about the final price and still lose a margined position to an earlier price swing. Tend gives that trader a different contract: the entry premium is the maximum loss, and the position survives until expiry.

The trade-off is explicit: the upside is capped, the premium can be lost in full, and an early exit depends on a fresh signed pool bid before expiry. An indicative mark is not an executable bid.

One trade, three promises

01 / BEFORE YOU BUY

Know the maximum loss

Choose UP or DOWN, a 15-minute, 1-hour or 12-hour schedule, and a 1.5×, 2× or 3× winning payout. Review the quoted strike, premium and exact expiry before signing.

02 / AT THE FILL

Lock the maximum payout

The vault escrows the full maximum payout when it accepts the signed quote. Pool utilization and position limits are enforced on-chain.

03 / BEFORE OR AFTER EXPIRY

Close or settle by clear rules

Before expiry, an eligible position can accept a fresh signed pool bid. If held, only the expiry settlement price decides its all-or-zero payout. If no settlement is published before the deadline, the contract supports a premium refund.

Why Monad

Tend combines frequent expiry schedules with quotes valid for just 30 seconds. Monad's low-latency EVM execution is a fit for that interaction: request a quote, confirm the fill, and inspect the collateral movement in the same flow.

These are actual Solidity contracts on Monad testnet. We are not claiming a measured throughput advantage over other chains; the demo evidence records real transaction receipts and reconciled balances.

What is running today

The trading experience

Live Coinbase BTC/ETH/MON data, fixed payout choices with quoted strikes, 15-minute / 1-hour / 12-hour expiry schedules, signed quotes, signed early-exit bids, position history and pool accounting. The exact expiry is shown because scheduled markets do not promise a fresh full tenor from purchase.

The protocol

TendSeriesFactory defines expiries and settlement. TendPoolVault checks EIP-712 quotes, escrows collateral and pays positions. The repository includes adversarial and fuzz tests for capped payouts and escrow conservation.

Testnet boundaries

Real prices; admin-posted oracle; mock collateral. Coinbase is a public, single-exchange data source. Settlement prices are posted to TendPriceOracle, which only Tend's admin key can write to — no trader can settle at an invented price. The admin is trusted and the price is not independently attested, so this is not a production settlement oracle.

Current operational gap. A local scheduler sweeps both testnets, but it depends on a funded laptop staying awake and online. Verify its recent logs and market availability before a rehearsal; reliable unattended operation remains required before a public launch.

A production release needs an authenticated oracle, independent security review, reliable keepers, and a deployment matched to reviewed source. This is an existing project being improved for Metropolis; prior work will be disclosed in the submission.
